> **Live demo is available at:** [https://finlectechnologies.com/](https://finlectechnologies.com/)

## 📁 Project Structure

```
finlectechnologies/
├── finlec-site/                              # Main website source code (React + Vite)
├── stitch_finlec_technologies_digital_agency_website/     # Design/stitch files (version 1)
├── stitch_finlec_technologies_digital_agency_website (1)/ # Design/stitch files (version 2)
├── stitch_finlec_technologies_digital_agency_website (2)/ # Design/stitch files (version 3)
└── package-lock.json                         # Node.js dependency lockfile
```

## 🛠️ Tech Stack

- **Frontend**: React.js + Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Lenis (smooth scroll)
- **Content**: MDX (blog posts)
- **Email**: EmailJS
- **Design**: Stitch / Figma-based design files
- **Package Manager**: npm

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Adityapatil0122/finlectechnologies.git
   cd finlectechnologies
   ```

2. **Navigate to the site folder**
   ```bash
   cd finlec-site
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   Visit `http://localhost:5173` in your browser.

## 🏗️ Build for Production

```bash
cd finlec-site
npm run build
```
