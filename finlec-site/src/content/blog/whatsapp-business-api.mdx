# When the WhatsApp Business API actually pays off

WhatsApp open rates are still 4–6× email. But the API is a chore: template approvals, opt-in mechanics, billing per conversation, and a dashboard that fights you.

It's worth the chore when:

- **Repeat purchase is high** (D2C, food, beauty).
- **Service touch is frequent** (logistics, fintech, education).
- **You already have CRM data** to segment by.

Otherwise, ship better email first.
