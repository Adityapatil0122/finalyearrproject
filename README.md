# Finlec Technologies 🚀

Welcome to the official repository for **Finlec Technologies** — a modern digital agency specializing in innovative web solutions, design, and technology services.

## 📁 Project Structure

```
finlectechnologies/
├── finlec-site/                              # Main website source code
├── stitch_finlec_technologies_digital_agency_website/     # Design/stitch files (version 1)
├── stitch_finlec_technologies_digital_agency_website (1)/ # Design/stitch files (version 2)
├── stitch_finlec_technologies_digital_agency_website (2)/ # Design/stitch files (version 3)
└── package-lock.json                         # Node.js dependency lockfile
```

## 🌐 About

Finlec Technologies is a digital agency website project built to showcase services, portfolio, and capabilities. The project includes multiple design iterations and a fully developed site.

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Design**: Stitch / Figma-based design files
- **Package Manager**: npm

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Adityapatil0122/finlectechnologies.git
   cd finlectechnologies
   ```

2. **Navigate to the site folder**
   ```bash
   cd finlec-site
   ```

3. **Install dependencies** (if applicable)
   ```bash
   npm install
   ```

4. **Open in browser**
   Open `index.html` in your browser or use a local development server.
