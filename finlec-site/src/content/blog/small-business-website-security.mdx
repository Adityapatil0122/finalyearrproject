# Website security basics small businesses should not skip

A business website does not need to be complicated to become risky. Weak passwords, outdated plugins, missing backups, and unmanaged access can turn a normal site into an expensive incident.

CISA's small business guidance focuses on practical security actions because small teams often do not have a dedicated security department.

## Start with the account layer

Use:

- Multi-factor authentication for admin accounts.
- Separate user accounts instead of shared logins.
- Least-privilege access for editors and vendors.
- Strong password rules and password manager adoption.

## Protect the website itself

The basics are not glamorous, but they work:

1. Keep CMS, plugins, themes, and dependencies updated.
2. Remove unused plugins and inactive accounts.
3. Enable SSL everywhere.
4. Back up files and database on a schedule.
5. Store backups away from the hosting account.
6. Monitor uptime, forms, and suspicious changes.

## Plan for recovery

Security also means knowing what happens if something breaks.

Document:

- Who owns hosting, DNS, email, and backups.
- How to restore the site.
- Who can approve emergency changes.
- Where analytics and Search Console access lives.
